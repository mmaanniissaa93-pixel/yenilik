# Alchemy

* The "Alchemy" tab allows you to easily improve your gear. It supports plussing items, using attribute/alchemic stones, and dismantling items to turn them into elements.
* To remove one item from the queue, right click it and click "Delete"

## Plus <a href="#alchemyplus" id="alchemyplus"></a>

Supports plussing regular items and using 12D+ enhancers.

<figure><img src="https://2872462270-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F2m4okFXMkt87rLgVVbFZ%2Fuploads%2FxjOBPtbZX95ZzG5Er9th%2Falchemy_plus.png?alt=media&amp;token=119f3f3a-c686-447d-8a47-ddd6ddb06069" alt=""><figcaption></figcaption></figure>

1. Stop at
   * Stop plussing when the item reaches a set plus.
2. Success delay
   * Time to wait after a successful plus.
3. Failure delay
   * Time to wait after a plus failure.
4. Lucky powder
   * Use lucky powder at a set plus and above.
5. Astral
   * Use Astral at a set plus and above.
6. Steady
   * Use steady at a set plus and above.
7. Immortal
   * Use an immortal stone at a set plus and above.
8. Lucky stone
   * Use a lucky stone at a set plus and above.
9. Stop after attempt

* Stop plussing after a set attempt count.

10. Add all items

* Adds all items that can be plussed to the list

11. Add

* Adds the current item to the queue with the settings you have specified.

12. Cancel

* Cancels plussing the item.

13. Start

* Starts the alchemy queue

14. Item

* The current item you wish to add to the queue.

15. Plus

* The current items plus value.

16. Success rate

* The current plus success rate.

17. Auto (item degree)

* Certain private servers change the lucky powder / weapon degrees. This option allows you to manually set the weapon / lucky powder degree. It is used for all alchemy tabs.

18. Move on after plus failure

* Move on to the next item in the queue if the plus fails.
* This is only useful on certain private servers.

19. Stop all alchemy if destroyed

* Stop alchemy if the item is destroyed.

20. Alchemy queue list

* This windows will show you all of the items you have added to the queue.
* You can add multiple items and multiple types (plus, attribute, alchemic).

## Attribute <a href="#alchemyattribute" id="alchemyattribute"></a>

<figure><img src="https://2872462270-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F2m4okFXMkt87rLgVVbFZ%2Fuploads%2Fk2VALsG36Z04nBUL4sUN%2Falchemy_attribute.png?alt=media&amp;token=378092a9-e727-440a-8c46-c9b8f4ba91b8" alt=""><figcaption></figcaption></figure>

1. Attribute stone type
   * The type of attribute stone to use on the item.
2. Stop at X %
   * Stop when the white value reaches this percentage or exceeds it.
3. Use alchemy catalyst
   * The bot is capable of using an alchemy catalyst with the stone.
   * Alchemy catalyst's prevent stones from failing.
4. Add All Items
   * Adds all inventory items to the queue for the selected stone.
5. Add All Stones
   * Adds all attribute stones for this particular item with the value you set.
6. Add
   * Adds the stone to the alchemy queue.
7. Cancel
   * Cancels using attribute stones on the item.
8. Start
   * Starts the alchemy queue.

## Alchemic <a href="#alchemyalchemic" id="alchemyalchemic"></a>

<figure><img src="https://2872462270-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F2m4okFXMkt87rLgVVbFZ%2Fuploads%2F7ZOLo8a9fJEbk4jKJC72%2Falchemy_alchemic.png?alt=media&amp;token=9eda50f6-b03d-40a6-9652-6d12dc7e7e4a" alt=""><figcaption></figcaption></figure>

1. Alchemic stone type
   * The type of alchemic stone to use on the item.
2. Stop at X value
   * Stop when the blue value reaches this or exceeds it.
   * The stop at value is NOT a percentage!
3. Use alchemy catalyst
   * The bot is capable of using an alchemy catalyst with the stone.
   * Alchemy catalyst's prevent stones from failing.
4. Add All Blues
   * Adds all possible blue stones for the item to the queue.
5. Add All Items
   * Adds all items in your inventory capable of using the stone you have selected.
6. Add
   * Adds the stone to the alchemy queue.
7. Cancel
   * Cancels using alchemic stones on the item.
8. Start
   * Starts the alchemy queue.

## Dismantle <a href="#alchemydismantle" id="alchemydismantle"></a>

<figure><img src="https://2872462270-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F2m4okFXMkt87rLgVVbFZ%2Fuploads%2FCNPwXCNBIcbgY1I7Kfp3%2Falchemy_dismantle.png?alt=media&amp;token=93e80e12-9a14-4ee6-8147-bc714da63ce2" alt=""><figcaption></figcaption></figure>

1. Add All Items
   * Adds all of your inventory items into the queue to be dismantled into elements.
2. Add
   * Adds one item that you have selected into the queue to be dismantled.
3. Cancel
   * Cancels the alchemy queue.
4. Start
   * Starts the alchemy queue.
