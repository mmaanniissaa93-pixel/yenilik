# Notifications

The "Notifications" tab shows you important information such as:

* Rare item has been picked
* Quest has been disabled
* GM has spawned near you
* Another player attacks you
* You die by a monster

This feature can be resource intensive so it should be turned off if you are experiencing lag. Some notifications will appear down by the tray icon when phBot is minimized.
