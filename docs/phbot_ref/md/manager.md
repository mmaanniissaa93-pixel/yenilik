# Manager

[**Download**](https://forum.projecthax.com/t/manager-release/45/)

The Manager is a free utility to manage multiple instances of phBot. It allows you to hide/show bots, start botting, and it will restart them if they disconnect. It automates the command line arguments for you and much more.
